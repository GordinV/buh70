# Сервис генерации и поиска Viitenumber (`get_viitenumber`)

## 1. Назначение и контекст
Сервис предоставляет веб-интерфейс для расчета и получения ссылочного номера (`viitenumber`), пояснения (`selgitus`) и данных учреждения на основе выбранного учреждения, типа документа и регистрационного номера / номера документа / личного кода.

---

## 2. Спецификация маршрутизации и безопасности
- **Маршруты Express:**
  - `GET /:hash/viitenumber` — отображение формы поиска/расчета.
  - `POST /:hash/viitenumber` — обработка отправленной формы и рендер страницы с результатами.
- **Валидация пользователя / хеша:**
  - На текущем этапе валидация выполняется через проверку фиксированного значения хеша:
    `hash === '2f2b7890e7951a55d589c2bb5df2d0f59cd10877'`.
  - При несовпадении хеша возвращается HTTP `403 Forbidden` (`Juurdepääs keelatud: vigane turvakood`).
- **Авторизация сессии:**
  - Стандартная сессионная авторизация (`checkAuth`) отключена (публичный доступ по хешу).

---

## 3. Входные параметры и форма ввода
Форма страницы содержит 3 обязательных параметра:
1. **Asutus (Учреждение) `rekv_id`:**
   - Выпадающий список (комбо), наполняемый из базы данных PostgreSQL:
     ```sql
     SELECT id, nimetus 
     FROM ou.rekv 
     WHERE status <> 3 AND (parentid = 0 OR parentid < 999) 
     ORDER BY nimetus;
     ```
2. **Tüüp (Тип документа / операции) `tyyp`:**
   - Выпадающий список фиксированных значений:
     - `1`: "Vanemate tasu"
     - `2`: "Kontraagent"
     - `3`: "Arve number"
3. **Dokumendi number / Reg. kood `objekt_number`:**
   - Текстовое поле ввода (номер счета, регистрационный код организации или личный код ребенка).

---

## 4. Обработка запроса (СУБД PostgreSQL)
Контроллер вызывает хранимую функцию:
```sql
SELECT libs.get_viitenumber_from_regkood($1::INTEGER, $2::TEXT, $3::TEXT) AS data;
```
Параметры:
- `$1`: `rekv_id` (INTEGER)
- `$2`: `objekt_number` (TEXT)
- `$3`: `tyyp` (TEXT, значение `'1'`, `'2'` или `'3'`)

Возвращаемый JSON-объект структуры `data`:
```json
{
  "error": false,
  "error_description": "Puuduvad andmed",
  "asutus": "Tallinna Lasteaed ...",
  "viitenumber": "100630012344",
  "selgitus": "Reg.kood: ... Nimetus: ..."
}
```

---

## 5. Выходные данные и пользовательский интерфейс
- **Рендеринг:**
  - Классический Server-Side Rendering (SSR) на шаблонизаторе Jade (`jade ~1.11.0`).
  - При отправке формы страница перезагружается с сохранением ранее выбранных значений (`rekv_id`, `tyyp`, `objekt_number`).
- **Отображаемые поля результата:**
  - `Viitenumber` — сгенерированный ссылочный номер.
  - `Selgitus` — детализированное пояснение (контрагент, ребенок, дата и сальдо счета).
  - `Asutus` — наименование учреждения.
  - `error_description` — вывод сообщения об ошибке при неудачном поиске / отсутствии данных.
